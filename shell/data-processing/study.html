第一章　物理实验的基本方法

1.1 物理实验思想和方法的形成（第 10 页）

教材以伽利略说明实验研究的双向过程。观察提出问题，理想化实验压缩影响因素，数学模型给出可检验的数量关系，真实实验再检验关系何时成立。测量出现偏离时，要分别检查被测量定义、装置与读数、模型近似，而后重新设计实验。单摆模型先忽略线和球的细节得到近似周期。精度要求提高后，再逐项估计球径、线质量和摆角的影响。

近代实验物理学把观察和实验定量化。教材把实验设计、装置制作、测量技巧和对数据的判断连成同一件事。即使程序准确算出了一个斜率，也要从实验设计上判断斜率是否对应预想的物理量、数据覆盖范围是否足够、模型在该范围内是否成立。

1.2 物理实验分析方法（第 10–14 页）

数量级排序和基本误差。 先把不同来源换算成对同一输出的绝对影响或相对影响，再按绝对值比较大小。第 11 页把“比主要影响至少小一个数量级”作为初筛准则。几项很小的影响可能方向一致。带符号的和估计合计修正，逐项绝对值之和给出保守界限，可用来检查遗漏项是否落在允许范围内。基本误差指给定仪器、操作和条件下实际能达到的误差底限，其来源可能是分辨率、计时反应、随机波动或环境约束。许多独立随机波动可用重复测量压低，稳定偏差可校准修正，杂散电容可通过屏蔽抑制，温度扰动可通过改变测量环境压低。一旦最主要的来源受到抑制，就重新排序。教材比较石英计时在普通、恒温和精密配置中的不同误差尺度，也用查德威克的历史例子说明，理论预测与观测相差若干数量级时应重新审查假说。

量纲分析。 指定候选物理量，写出它们在质量 M 、长度 L 、时间 T 等基本量纲下的指数，把未知指数写成线性方程。矩阵每一列是一个因素的量纲，同一行对应同一类基本量纲。若方程欠定，可由齐次方程的自由变量构造无量纲组合。若无解，应重新检查候选量或单位维度。无量纲常数或未知的无量纲函数需要其他物理条件或测量来确定。对中心天体质量 M 0 远大于绕行物体质量、且近似圆轨道的例题，试设 P ∝ M 0 a r b G c 。由 a − c = 0 ,   b + 3 c = 0 ,   − 2 c = 1 得 P ∝ r 3 / ( G M 0 ) ，于是 P 2 ∝ r 3 。 2 π 需要结合圆周运动关系确定。教材另一历史例把膨胀前沿的尺度和时间画在双对数图上，斜率约为 0.4 ，接着用量纲齐次检验候选变量是否与观测相容。对任意正值数据， ln ⁡ y = ln ⁡ A + b ln ⁡ x 的斜率就是 b 。

1.3 物理实验的基本测量方法（第 14–22 页）

测量是借助共同的基准确定量值。教材用日、月等天然周期、机械钟、石英钟和原子频标说明计时原理如何随精度升级，又从微观显微术到宇宙尺度说明相同物理量需要不同测量手段。书中光钟数值展现的是成书时的研究背景。选方法时先确定量程和目标不确定度，然后评估分辨率、最大允差、环境与操作者。

第二章　测量的不确定度和数据处理

2.1 测量的不确定度（第 24–43 页）

基本概念、仪器与记录（第 24–29 页）

被测量的定义取决于所要求的准确程度。例 1 中，名义长 0.5 m 的铜管若测至微米量级，定义可明确 20.00 ∘ C 、 101325 Pa 和支撑方式。若只测到毫米量级，影响远低于目标时可以简化定义。取样代表性、环境、示值偏倚、分辨力、标准物质、外部常量、近似模型和重复观测的涨落，都可能进入结果。

测量误差描述结果与参考量值之差。若讨论真值，真值未知就不能确知这个差。测量不确定度以非负数表示可以合理赋予被测量的量值有多分散。重复测量有助于压低均值的随机影响，校准可修正已知系统影响。例 2 中，有限内阻的电压表对高阻对象有负载效应。可以按两者阻值进行修正，阻值估计本身的不确定度随修正进入输出。A 类依赖对观测序列做统计分析，B 类根据证书、规格、既有资料或可辩护的分布假设评定。两类结果均以标准差的尺度进入合成。

计算全程保留额外数字，报告时通常将不确定度保留至多两位有效数字，将测量值修约到其末位所在的小数位。十进制恰好在中点时采用五凑偶，例如 1.2350 按 0.01 修约为 1.24 ， 1.2450 修约为 1.24 。若首个舍弃数字为 5 且后有非零数字，则超过中点，向较远的绝对值方向修约。第 41 页还单独说明扩展不确定度可按末位直接进位。原始量值只到不确定度首位时，可只报不确定度一位有效数字。末位相差多个数量级时检查遗漏项。角度例 y = sin ⁡ ( 30 ∘ 24 ′ ) 在示值允差 1 ′ 、矩形分布下有 u ( θ ) = π / ( 180 × 60 3 ) ≈ 1.68 × 10 − 4 rad ， u ( y ) ≈ 1.45 × 10 − 4 ，给出约 0.50603 的估计值。一般先传播分辨影响，再决定函数值位数。

A 类、B 类和常见分布（第 29–34 页）

取独立、近似同条件的 n 个读数 q i ，按下式计算均值与标准不确定度。

q ¯ = 1 n ∑ i q i , s 2 = ∑ i ( q i − q ¯ ) 2 n − 1 , u A ( q ¯ ) = s n , ν = n − 1.

s 表示单次观测的散布， s / n 表示均值的散布。用一个均值消耗了一个自由度。若常规程序已用预先的多组独立测量验证稳定性，可把组内方差按 ν j = n j − 1 加权合并， s p 2 = ∑ j ν j s j 2 / ∑ j ν j 。新测量 m 次的均值使用 s p / m ，单次使用 s p 。用本次 m 个值独立估计时，自由度为 m − 1 ，使用外部合并标准差时采用该标准差的自由度。第 30 页把 m − 1 写进了预评定流程，而第 51 页量块实例把此前 25 次评定的自由度 24 用于后续 5 次的均值。不具备事前资料又只有一次测量时，无法从这一个值估计重复性。

释放时保持小角度、同一竖直平面和可辨识的过零参考位置，记录 N 和总时间 t N 。同方向经过同一个参考位置才算一个完整周期。理想模型给 g = 4 π 2 l / T 2 ，采用第 1.2 节书中修正时给 g = 4 π 2 l F / T 2 ，其中 T = t N / N 。分别重复记录摆长与时间，求各量的 A/B 分量。小角理想模型下，若 l , T 独立，

u ( g ) g = ( u ( l ) l ) 2 + ( 2 u ( T ) T ) 2 .

主要贡献来自计时时，可增加 N 或用光电门，同时留心阻尼与计数错误。摆长可能由线长和半个球径合成，基准要选悬点到球心。在进阶设计中按同一覆盖尺度比较 Δ g / g < 1 % 的预算。给定总计时标准不确定度 u ( t N ) 并求出可用单周期标准不确定度上限 u max ( T ) 后，最少累计周期数为 u ( t N ) / u max ( T ) 向上取整且至少为 1。若摆长项已用尽预算，应先改进摆长测量。采用修正模型时， F 也随 l 变化。前面的相对式是小角理想模型使用的式子，同步考虑几何、质量、密度或摆角的波动时，应把相应输入纳入通用传播。

对于大摆角或圆锥摆，教材建议以逐帧轨迹比较模型。大摆角可由连续同向过平衡位置的两个时刻提取周期，用该区间峰值估计振幅 θ 0 。理想的无阻尼固定平面单摆满足 T = 4 l / g K ( sin ⁡ ( θ 0 / 2 ) ) ，其中 K 是第一类完全椭圆积分。把 4 l K ( sin ⁡ ( θ 0 / 2 ) ) 作为横轴，测得周期作为纵轴，过原点的回归斜率是 1 / g 。这与小角近似中的节拍比较相容，也便于检查振幅对周期的影响。圆锥摆稳态可用俯视轨迹估计半径 r 和周期 T ，以 tan ⁡ θ = r / l 2 − r 2 连接几何，并检验 T 2 = 4 π 2 l cos ⁡ θ / g 。

B　自由落体法（第 65–66 页）

从静止开始的模型为 h = g t 2 / 2 。图 2-4-2 用电磁铁释放小球，竖直立柱上设光电门、卷尺和数字毫秒计，底部用纸杯接球。断电到脱离有剩磁延迟，教材估计可到 20 ms 。实验测两个光电门之间的间隔，避免以电磁铁断电瞬间作为运动的时间零点。

将第一门固定，保持球经过它时的速度 v 0 尽可能一致。把第二门移至 6–8 个位置，记录每组门间距 h i 和门间时间 t i 。由 h i = v 0 t i + g t i 2 / 2 ，以 x i = t i 、 y i = h i / t i 回归，截距为 v 0 ， g = 2 m ，拟合标准误 s g = 2 s m 。作图查异常，再说明高度、闸门时间零点和空气阻力。时间 t i 同时参与两轴，若其误差不可忽略，要说明普通最小二乘法忽略横轴误差的近似。

思考题的要点是单段短时间会把计时影响按约 2 u ( t ) / t 传到 g ，断电滞后还会引入系统影响。第一门位置应固定并处于重复落体轨迹上，第二门的多个位置应给出足够时间跨度，同时避免门间距太小或球未正穿门。替代方案可用通过光电门时的已知遮光宽度估计瞬时速度，以 v 2 2 − v 1 2 = 2 g h 进行独立比较。所有高度与时间先换算到同一单位制。

用不确定度预算选择仪器（第 66–67 页）

对于直径 D 和高度 h 独立的圆柱体， V = π D 2 h / 4 ，所以相对标准预算是

u ( V ) V = 4 ( u ( D ) D ) 2 + ( u ( h ) h ) 2 .

教材例中 D ≈ 8.0 mm , h ≈ 32.0 mm ，目标为 U ( V ) / V ≤ 0.5 % ，近似 k = 3 。千分尺测 D ，以 0.004 mm / 3 作标准贡献，逆算得 u ( h ) ≲ 0.0523 mm ，高度可选课本实例中的游标卡尺。若反用允差 0.02 mm 且假设矩形的卡尺测直径，仅直径贡献扩展后就约 0.866 % ，已经超标。所需的仪器精度由 | c i | u i 的贡献决定。均分可作初始预算，最终应检查真实的分项预算能否达标。

长度量具与时间量具（第 67–70 页）
  • 长度基准与尺度。 米与真空光速相联，等价说法是一米为光在 1 / 299792458 秒内在真空走过的距离。不同长度尺度使用不同工具，教材落到三种实验室量具。
  • 游标卡尺（图 2-4-3）。 可测外径、内径、厚度和深度等。主尺最小分格 1 mm ，10、20、50 格普通游标给 0.1 , 0.05 , 0.02 mm 的细分。先读位于游标零线左侧的主尺刻度，再加对齐刻线序号乘游标分度，最后扣除带符号的闭合零读数。教材实例按对齐刻线确定小数位。
  • 螺旋测微器（图 2-4-4）。 常见螺距 0.5 mm 、旋筒 50 格，分度为 0.01 mm 。读固定套筒整毫米与露出的半毫米，再加微分筒读数乘分度值，可按教材估读到 0.001 mm 。减去闭合零读数，并用棘轮获得较可控的测量力。
  • 读数显微镜（图 2-4-5）。 示例螺距 1 mm 、鼓轮 100 格，整毫米数加鼓轮分度所得小数。调光、对焦，用同方向转动的十字线分别对准两个参考点，取读数差的绝对值。若越过参考点，重新沿同方向接近以限制回程差。
  • 时间基准与仪表。 秒可由铯-133 原子基态超精细跃迁频率 9 192 631 770 Hz 表述。电子秒表以石英时基累计显示，教材示例分辨力 0.01 s ，还需考虑人的启停。数字毫秒计以电子时基配合光电门，教材设备例分辨力 0.1 ms 、计时误差小于 0.5 ms 。两者共同的计算步骤是明确时间端点、统一单位、区分显示分辨力和触发或同步误差。
